## What's broken / why we need admin
1. **TDR timeout not fixed.** `HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers`
   has no `TdrDelay` override (default 2s). The paper's own root-cause finding for
   the ORIGINAL null result was a silent TDR-triggered CUDA kernel abort during
   training that corrupted gradients without raising an exception. Fix before any
   real training run:
   ```
   reg add "HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers" /v TdrDelay /t REG_DWORD /d 60 /f
   ```
   Needs a reboot to take effect — the lab wipes on reboot too, so do this FIRST,
   reboot, then redo the rest of setup below in the same elevated session after
   the reboot.

## The positive-control experiment plan (proposed to the user, not yet run)
Same 918-pair corpus (`data/dpo_pairs_capped.jsonl`), same LoRA config (r=16,
α=32, dropout .05, same 7 target modules), but:
- `--lr 2e-4` (~40x the paper's 5e-6 baseline — standard-for-LoRA rather than the
  unusually low rate the original run used)
- `--epochs 3`
- n=15 replicates/arm (not 40 — retrains in the paper already show huge effects
  significant well below n=40; smaller n fits inside one lab session)
- Same-session, interleaved arms (positive-control adapter vs a freshly-served
  null), matching the paper's own four rules in `poscontrol/START-HERE.md`:
  never compare across sessions, verify tools on a known answer first, match
  verifier fingerprints, interleave don't block.
- **Decision rule, fixed before training starts**: Welch's t-test, two-sided,
  α=.05, on run-level pass@1. Success = p<.05 AND effect ≥5pp in the positive
  direction. Write this to `data/prereg_positive_control.json` BEFORE training,
  matching the `prereg_track_a_run1.json` convention (hashes derived
  programmatically from live artifacts, not typed).

Train:
```
.\.venv-train\Scripts\python.exe train_native.py --lr 2e-4 --epochs 3 --out dpo_adapter_poscontrol
```
Then export via `export_adapter.py` (check its docstring/CLI), serve via Ollama
`ADAPTER` directive (see `poscontrol/served/Modelfile.*` for the pattern), then
`ruler_noise.py measure --runs 15 --model <tag>` for both arms, interleaved.
